# ohttp

**Oblivious HTTP for OCaml.** This repository holds two packages: `bhttp`, a
codec for Binary HTTP ([RFC 9292](https://www.rfc-editor.org/rfc/rfc9292.html)),
and `ohttp`, an implementation of Oblivious HTTP
([RFC 9458](https://www.rfc-editor.org/rfc/rfc9458.html)) over the
[`hpke`](https://github.com/thevilledev/ocaml-hpke) package.

> **Status:** under construction, unaudited, and not production-ready.
